# Personal Finance Control App

A minimalist and intuitive **personal finance management web app**, developed to help track income, expenses, and balance in real time — built using **HTML, CSS, and JavaScript**.  

This project was created as a **personal experiment and study**, developed by **Bruno Lorran Sanches do Vale** in collaboration with **ChatGPT**, to practice and enhance skills in **front-end development, UI design, and data handling with Local Storage**.

---

## 🧭 Overview

The Finance Control App was designed to be simple yet functional — combining clean aesthetics with practical daily-use features.  
It allows the user to **record financial transactions**, **view a running balance**, and **analyze spending categories**, all in a single lightweight interface.

> 💡 This project was not meant for commercial use — it’s a **learning experiment** that merges design sensibility with programming logic.

---

## 🛠️ Technologies Used

| Category | Stack |
|-----------|--------|
| **Structure** | HTML5 |
| **Style** | CSS3 (custom + responsive layout) |
| **Logic** | JavaScript (ES6) |
| **Storage** | Local Storage API |
| **Design** | Custom minimalist UI by Bruno Lorran |

---

## ✨ Features

- 📊 Real-time balance calculation  
- ➕ Add and remove transactions dynamically  
- 🏷️ Categorize expenses and incomes  
- 💾 Persistent data with Local Storage  
- 💡 Clear and modern interface design  

---

## 🧠 Learning Focus

This project was part of my personal development journey to:
- Strengthen my **JavaScript and DOM manipulation** skills  
- Practice **data persistence** without a database  
- Explore **UX and UI principles** in financial visualization  
- Learn how to build, refactor, and structure small front-end applications
